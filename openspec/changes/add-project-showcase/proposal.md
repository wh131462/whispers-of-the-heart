## Why

站点当前只能展示硬编码的站内工具，应用分发模块也仅提供版本更新接口，缺少一个可由后台维护、同时覆盖开源项目和独立 APP 的公开作品展示入口。新增作品展示可以让访客在首页和独立页面快速了解博主的代表作品，并减少重复维护应用下载信息。

## What Changes

- 新增公开“作品”能力，支持开源项目、APP、网站和站内工具四类作品。
- 新增作品公开列表接口，公开结果仅包含已上线作品，并支持首页精选查询。
- 新增管理员作品 CRUD，支持封面、图标、标签、平台、链接、上线状态、首页推荐和排序配置。
- 作品可选关联现有应用分发记录；关联后公开数据提供该应用的最新版本和 APK 下载地址。
- 前台新增 `/projects` 作品页、顶部导航入口和首页精选作品区域。
- 后台新增独立“作品管理”页面，复用现有媒体库选择能力。

## Capabilities

### New Capabilities

- `project-showcase`: 规范作品的管理、公开查询、应用分发关联与前台展示行为。

### Modified Capabilities

无。

## Impact

- 数据库：新增作品类型、状态和作品模型，并与 `DistributedApp` 建立可选关联。
- API：新增 `project-showcase` NestJS 模块及管理员/公开 REST 接口。
- Web：新增作品类型、展示组件、公开页面、首页区域、导航项和后台管理页。
- 现有 `apps` 站内工具注册表与应用分发更新 JSON 的行为保持不变。
- 不引入新的运行时依赖。

## Non-goals

- 不自动同步 GitHub Stars、README、Release 或应用商店数据。
- 不在首版提供独立作品详情页或富文本作品编辑器。
- 不把现有站内工具自动迁移为后台作品记录。
