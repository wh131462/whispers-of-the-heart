## Why

当前系统没有集中维护客户端应用版本及提供机器可读更新信息的能力，应用发布后只能通过手工约定版本与下载地址。新增应用分发模块，使管理员可注册应用、维护版本历史，并为客户端提供稳定的公开更新检查接口。

## What Changes

- 在管理后台新增“应用分发”页面，支持注册、编辑、删除应用并查看其更新接口。
- 支持为应用创建、编辑和删除版本，保存 `versionCode`、`versionName`、HTTPS `apkUrl` 与可选 `releaseNotes`。
- 新增无需认证的按应用标识查询最新版本接口，直接返回客户端所需 JSON 字段。
- 使用 Prisma 持久化应用与版本历史，并通过管理员权限保护所有写操作。

## Capabilities

### New Capabilities

- `app-distribution`: 应用注册、版本历史管理以及公开最新版本 JSON 接口。

### Modified Capabilities

无。

## Impact

- 后端：新增 NestJS 应用分发模块、DTO、管理员 CRUD 与公开查询路由。
- 数据库：新增应用与应用版本两张表及级联关系。
- 前端：新增管理页面、路由与侧边栏入口，沿用现有 API 客户端和管理端组件模式。
- 依赖：不引入新依赖。

## Non-goals

- 不负责 APK 文件上传、签名、病毒扫描或对象存储生命周期管理。
- 不实现灰度发布、渠道分发、强制更新、下载统计或客户端鉴权。
- 不改变生产环境 TLS/HTTPS 终止方式；公开接口是否经 HTTPS 访问由现有部署入口保证。
